## Главное
- Не копируй данные пользователей из продакшена в личные заметки, чаты и внешние сервисы.
- Не вставляй конфиденциальную информацию во внешние ИИ-сервисы.
- Ознакомься с лендингом «Защита данных», памяткой по раскрытию информации и политикой по работе с КИ — это шаг плана первого месяца.
