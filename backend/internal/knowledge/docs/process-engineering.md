## Zero Bug Policy
Баги не копятся в бэклоге: у каждого бага есть срок исправления в зависимости от критичности. Новые фичи не берутся, пока есть просроченные баги.

## Код-ревью
Каждый merge request смотрят минимум двое, один из них — наставник на время стажировки. Небольшие MR ревьюят быстрее.
