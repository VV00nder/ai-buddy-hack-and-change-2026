## Grafana
Дашборды сервисов: RPS, латентность, ошибки. Начни с дашборда своего сервиса — ссылка в README репозитория.

## Sentry
Исключения и ошибки сервисов. Подпишись на алерты своего сервиса.

## Observer
Трассировка запросов между микросервисами: удобно разбирать, где тормозит цепочка.

## Redash
SQL-запросы к аналитическим данным. Доступ — по обоснованию через руководителя.
