# Сценарий защиты (8–10 минут)

Роли: **ведущий** рассказывает, **демонстратор** ведёт живое демо, остальные отвечают на вопросы по своим зонам (бэкенд и MCP, агент и безопасность, интерфейс, метрики). Каждый участник должен уметь пройти демо сам — критерий «командное владение решением».

## Подготовка (за 10 минут до выхода)
- `docker compose down -v && docker compose up --build -d`, открыть http://localhost:8080 в двух окнах: стажёр и руководитель.
- Проверить `GET /api/config`: режим `llm`, если есть ключ; иначе офлайн — это нормально, так и говорим.
- Запасной план: видео `docs/demo/ai-buddy-demo.mp4` и PDF.

## Тайминг
| Время | Слайд / демо | Что сказать |
|---|---|---|
| 0:00–0:40 | 1–2 | Наставник тратит до 65 часов на стажёра, заметная часть — на одни и те же вопросы и оформление. |
| 0:40–1:20 | 3–4 | Три вещи: отвечает со ссылкой, ведёт по плану, оформляет заявки. Путь стажёра по чек-листу Авито, 5 сценариев. |
| 1:20–5:30 | **Живое демо** | См. ниже. |
| 5:30–6:30 | 10–11 | Стек Авито, MCP как граница с сервисами, что меняется при внедрении. |
| 6:30–7:30 | 12–13 | Права в коде, а не в промпте; подтверждение действий; SDD и тесты 94,8% / 90,9%. |
| 7:30–8:30 | 14–15 | Как проверяем эффект (A/B по командам), что дальше. |

## Живое демо (4 минуты)
1. **Анна** → подсказка «Мне нужен отгул…» — ответ с источником и «руководителя отвлекать не нужно».
2. «Оформи отгул на …» → стикер-черновик → поправить причину → «Отправить заявку» → штамп «На согласовании». Обратить внимание: шаги агента видны, пока он работает.
3. «Запроси доступ к stash на запись» → AI-buddy спрашивает проект → `search-api` → в черновике проект, уровень и согласующий — владелец проекта Олег (как в Авито: согласует тот, кто отвечает за ресурс). «Дай доступ к kubernetes» → отказ сервиса и альтернатива. Фраза: «Права проверяет сервис, а не промпт».
4. «Где посмотреть тестовый стенд поиска?» → «Отправить наставнику».
5. **Окно руководителя (Мария)** → «Согласования» → согласовать отгул с комментарием. «Стажёры» → Анна: цели с критериями успеха.
6. **Олег** → «Согласования»: доступ к Stash; «Вопросы стажёров»: ответить, «Сохранить в базу знаний».
6a. Вызвать ИИ-крон (`curl -X POST localhost:8080/api/cron/reminders -H "X-Cron-Token: demo-cron"`) → у Анны в чате утренняя сводка.
7. **Анна** → колокольчик, ответ наставника в чате, повторный вопрос закрыт сразу. «Мой план» — шаг закрылся сам (если запрашивали Stash).
8. **Мария → «Польза»** — доля вопросов без наставника, сэкономленные часы.

Если что-то пошло не так — не чинить на сцене: «покажу на видео» и включить нужный момент.
