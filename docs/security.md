# Безопасность и данные

## Права доступа
- **База знаний:** документы имеют `audience` и `team`; фильтр применяется до поиска и до передачи текста в LLM. Стажёр не видит методичку наставника и материалы калибровки; чужая команда не видит документы и FAQ команды.
- **Инструменты:** список MCP-инструментов фильтруется по роли на стороне сервиса; инструменты решений руководителя не передаются агенту вообще.
- **Сервисы:** каждый сервис проверяет подписанный токен пользователя: роль, принадлежность заявки, согласующего. Чужой руководитель не может согласовать заявку.
- **Сервисный слой:** стажёр меняет только свои шаги; наставник и руководитель — шаги своих стажёров; действия и вопросы видны только владельцу и адресату.

## Действия
Ни одно действие не выполняется без нажатия кнопки пользователем. Модель вызывает инструменты записи только в режиме `dry_run`; это выставляет оркестратор. Пользователь может поправить разрешённые поля (даты, причина, обоснование, текст вопроса), служебные поля (`system`, `type`) не редактируются.

## Веб
- Сессия — случайный идентификатор в cookie `HttpOnly`, `SameSite=Lax` (`Secure` включается `COOKIE_SECURE=true`); данные сессии в Redis с TTL 12 ч.
- CSRF: изменяющие запросы обязаны иметь заголовок `X-Requested-With: ai-buddy`.
- CSP `default-src 'self'`, `X-Frame-Options: DENY`, `nosniff`.
- Ответы ассистента рендерятся без `innerHTML` — HTML из текста экранируется.
- Лимиты: тело запроса 64 КБ, сообщение 2000 символов, 20 сообщений в минуту.

## Приложение на телефоне (PWA)
Service worker кэширует только оболочку и статические файлы с хешем в имени. Запросы к `/api/*` идут только в сеть: история диалога, заявки и данные плана не сохраняются на устройстве. `sw.js` и манифест отдаются с `Cache-Control: no-cache`, поэтому обновления доходят сразу.

## Данные
Все сотрудники, инструкции и заявки синтетические. Больничные, зарплата, финансовые операции вне области задачи — агент направляет к HR BP. В событиях аналитики нет текста сообщений.

## Prompt injection
Инструкции внутри документов игнорируются по промпту, но защита не полагается на промпт: закрытые документы не попадают в контекст, недоступные инструменты не передаются, сервисы перепроверяют права, а отправка требует подтверждения человеком.
