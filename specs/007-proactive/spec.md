# 007. Проактивные напоминания (ИИ-крон)

Основание: в Авито есть внутренний ИИ-крон; эксперты разрешили имитировать API внутренних инструментов. AI-buddy предоставляет точку вызова `POST /api/cron/reminders` (служебный токен `X-Cron-Token`), а для локального стенда — встроенный таймер (`REMINDER_INTERVAL_MINUTES`). Включается флагом `FF_PROACTIVE`.

## Пользовательские истории
- **Стажёр** утром получает в чат сводку: день стажировки, начало нового этапа, просроченные шаги, следующий шаг с кнопкой-подсказкой.
- **Согласующий** получает напоминание, если заявка стажёра ждёт решения больше суток.
- **Наставник** получает напоминание о вопросе стажёра без ответа больше суток.

## Критерии приёмки
| # | Дано | Когда | Тогда | Тест |
|---|---|---|---|---|
| 1 | Неверный токен | Вызов крона | 403 | `TestCronReminders` |
| 2 | Два стажёра | Первый прогон за день | По одной сводке каждому, в чате сообщение «Напоминание AI-buddy» | `TestCronReminders` |
| 3 | Повторный прогон в тот же день | — | Сводки не дублируются | `TestCronReminders` |
| 4 | Заявка на отгул ждёт 2 дня | Прогон | Руководитель получил «… ждёт решения 2 дн.» | `TestCronReminders` |
| 5 | Вопрос наставнику без ответа > 24 ч | Прогон | Наставник получил напоминание | `TestCronReminders` |
| 6 | `FF_PROACTIVE=false` | Прогон или таймер | Ничего не отправляется | `TestCronReminders` |
