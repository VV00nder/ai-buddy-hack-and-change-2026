# 009. Шаблоны обучения и программа под стажёра

Основание: стажёры разных направлений проходят разную адаптацию (разработчик, аналитик), а у конкретного человека может быть свой опыт. Чек-лист Авито — базовый шаблон.

## Пользовательские истории
- **Руководитель или наставник** выбирает шаблон обучения из встроенных («Стажёр-разработчик», «Стажёр-аналитик») или шаблонов своей команды.
- Встроенный шаблон можно **скопировать** и изменить: добавить, убрать, переставить шаги, указать, кто отмечает шаг и каким тестом он закрывается.
- **Назначает** шаблон стажёру; программа стажёра — копия шаблона, поэтому правки шаблона не ломают текущие программы.
- **Настраивает программу под конкретного стажёра**: убирает лишнее, добавляет свои шаги. В плане видно «настроена индивидуально».
- **Стажёр** получает уведомление, план обновляется сразу; AI-buddy подсказывает шаги новой программы.

## Критерии приёмки
| # | Дано | Когда | Тогда | Тест |
|---|---|---|---|---|
| 1 | Наставник / стажёр | Список шаблонов | 2 встроенных + шаблоны команды / 403 | `TestTemplatesAndPrograms` |
| 2 | Встроенный шаблон | Изменение или удаление | 400 «сделайте копию» | `TestTemplatesAndPrograms` |
| 3 | Копия с новым шагом без id | Сохранение | Шаблон команды, шагу присвоен id | `TestTemplatesAndPrograms` |
| 4 | Шаг с неизвестным этапом или тестом | Сохранение | 400 | `TestTemplatesAndPrograms`, `TestTemplates` |
| 5 | Шаблон другой команды | Список | Не виден | `TestTemplatesAndPrograms` |
| 6 | Наставник стажёра / чужой наставник | Назначение шаблона | План стажёра по новому шаблону / 403 | `TestTemplatesAndPrograms` |
| 7 | Руководитель | Убирает шаг и добавляет свой | `customized`, число шагов изменилось, стажёр отмечает свой шаг | `TestTemplatesAndPrograms` |
| 8 | Пустая программа | Сохранение | 400 | `TestTemplatesAndPrograms` |
| 9 | Шаблон удалён | — | Программа стажёра не изменилась | `TestTemplatesAndPrograms` |
| 10 | Назначение или настройка | — | Стажёр получил уведомление | `TestTemplatesAndPrograms` |

## Требования
- Отметки совпадающих шагов сохраняются при смене шаблона (состояния хранятся по id шага).
- Автозакрытие шагов по выданным доступам и по сданным тестам работает для любой программы.
